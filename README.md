# فك كروت الاهرام 📇

أداة ويب **آمنة 100%** لاستخراج أكواد وسيريالات كروت الشحن من ملف فاتورة إكسل.

> 🔒 **كل المعالجة تتم داخل متصفحك.** لا يُرفع ملفك إلى أي خادم، ولا يُحفظ أي شيء في أي مكان. ترفع ملف الكروت ← يخرج لك ملف الكروت — والبيانات لا تغادر جهازك إطلاقاً.

---

## ✨ المميزات

- 📤 رفع ملف الإكسل (.xlsx / .xlsm / .xls) بالسحب أو الاختيار.
- 🧠 اكتشاف تلقائي لأوراق المنتجات وتجاهل ورقة الملخص.
- 🔀 **اكتشاف مرن للأعمدة:** يجد عمود الكود وعمود السيريال مهما تغيّر مكانهما أو اختلفت تسميتهما بين الفواتير (يدعم «الكود» و«الرقم السري (PIN)» وغيرها). إذا كان عمود «الكود» فارغاً يأخذ الكود تلقائياً من عمود «الرقم السري (PIN)» ويُعلمك بذلك.
- 🪟 **نافذة تأكيد كود الفئة** لكل ورقة (العمود الرابع) — تعدّله أو توافق مباشرة، مع زر «موافقة على الكل».
- 📦 **خيار دمج فئات كل شركة** في ملف واحد خاص بها (يميّزها كود الفئة).
- 📥 تنزيل النتيجة: ملف CSV واحد، أو ملف ZIP منظّم (مجلد لكل شركة) عند تعدد الملفات.
- ⚠️ **تنبيهات النواقص:** ينبّهك إذا كانت أي فئة/ورقة فيها نقص (كرت بدون سيريال، كرت بدون كود، عمود ناقص، أو كود فئة فارغ) بأسطر صفراء واضحة + شريط تنبيه.
- 🛡️ **إثبات الخصوصية:** بعد كل عملية يعرض عدّاد **طلبات الشبكة = 0** للتأكيد المباشر أن لا شيء يُرفع.
- 🌐 يعمل **بدون إنترنت** بعد فتح الصفحة، وبدون أي خوادم.

## 🧾 شكل المخرجات

كل صف في ملف CSV (بدون رأس جدول، ترميز UTF-8):

| العمود 1 | العمود 2 | العمود 3 | العمود 4 |
|----------|----------|-----------|----------|
| الكود | السيريال | كود الشركة | كود الفئة |

**أكواد الشركات:** Vodafone = `010` · Etsalat/Etisalat = `011` · Orange = `012` · We = `015`
(تُطابَق أيضاً بالأسماء العربية: فودافون / اتصالات / اورانج / وي)

## 🛡️ لماذا هي آمنة؟

- التطبيق **ثابت (Static)** بالكامل: HTML + CSS + JavaScript فقط.
- قراءة الإكسل وتوليد CSV يتمّان في المتصفح عبر مكتبتي [SheetJS](https://sheetjs.com) و [JSZip](https://stuk.github.io/jszip/) **المُضمَّنتين محلياً** داخل المشروع (مجلد `vendor/`) — لا يوجد أي استدعاء لطرف ثالث وقت التشغيل.
- لا يوجد كود خادم، ولا قاعدة بيانات، ولا تخزين. يمكنك التأكد بفتح تبويب Network في المتصفح: لا توجد أي عملية رفع.

## 🚀 التشغيل

- **محلياً:** افتح ملف `index.html` مباشرة في المتصفح.
- **على الويب (GitHub Pages):** فعّل صفحات GitHub من إعدادات المستودع
  (Settings → Pages → Branch: `main` / المجلد: `/root`)، وسيُنشر الموقع تلقائياً.

## 📁 بنية المشروع

```
.
├─ index.html            # الواجهة
├─ assets/
│  ├─ style.css          # التنسيق
│  └─ app.js             # منطق الاستخراج
└─ vendor/
   ├─ xlsx.full.min.js   # SheetJS (قراءة الإكسل)
   └─ jszip.min.js       # JSZip (توليد ZIP)
```
