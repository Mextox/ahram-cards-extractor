فك كروت الاهرام

استخراج الأكواد والسيريالات من ملف الفاتورة

by: Mohaned

🔒 خصوصية كاملة: كل المعالجة تتم داخل متصفحك. لا يتم رفع ملفك إلى أي خادم، ولا يُحفظ أي شيء.
🔎 كيف أتأكد بنفسي أنه يعمل داخل المتصفح ولا يرفع شيئاً؟
  1. اقطع الإنترنت بعد فتح الصفحة ثم جرّب الاستخراج — سيعمل كاملاً بدون اتصال، لأن كل المعالجة محلية.
  2. افتح أدوات المطور (F12) ← تبويب Network ← استخرج ملفاً: لن ترى أي عملية رفع (upload) لملفك.
  3. بعد كل عملية يعرض البرنامج في السجل عدّاد طلبات الشبكة أثناء المعالجة = 0 كإثبات مباشر.
  4. الكود مفتوح المصدر بالكامل ويمكنك مراجعته على GitHub.
